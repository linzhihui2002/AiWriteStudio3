# 去 AI 味规则库（human-linguistics）

## 定位

本技能只描述**规则与手法**，不复述任何外部文本。
所有数值阈值不在本文件硬编码，一律**引用**门禁模块的常量：

| 阈值 | 引用位置 |
|---|---|
| 破折号密度上限 | `workbench.backend.gates.density_gate.DASH_LIMIT` |
| 对话密度上限 | `workbench.backend.gates.density_gate.DIALOG_MIN` |
| 禁词表 | `workbench.backend.gates.density_gate.DEFAULT_FORBIDDEN` |
| 三连排比模式 | `workbench.backend.gates.density_gate.TRIPLE_PATTERNS` |
| 硬停词 / 黑话 / 模型路标 | `workbench.backend.gates.prose_gate` 对应常量 |

引用而非复制：阈值只有一处事实源，改配置不改技能文本。

## 规则清单

### R1 停顿不要用破折号顶替
破折号是最典型的 AI 停顿符号。停顿优先用句号，悬停/拖音优先用省略号。
判定：破折号密度不得超过 `DASH_LIMIT`（每 N 字 1 个）。

### R2 对话是节奏工具，不是装饰
连续叙述堆砌会让文本失去呼吸。判定：对话引号密度须达到 `DIALOG_MIN`
（每 N 字至少 1 次），低于该值即「叙述堆砌」。

### R3 推测词在叙述层零容忍
「似乎 / 显然 / 大概 / 略显」等推测词属于作者替读者下判断。
叙述层命中即删；角色口语吐槽语境由人工判断保留。

### R4 三连排比全禁
「不是A，不是B，不是C」「没有A，没有B，没有C」「记得X，记得Y，记得Z」
是模型最稳定的句式指纹。保留两项，第三项换说法或删除。

### R5 删掉升华腔
「这一刻」「他终于明白」「这就是……的意义」属总结/点题句式，出现即提示，
人工判断是否删除。正文不负责替读者总结。

### R6 具体数字优于形容词
具体数字是人工写作特征。能用数字、专名、可验证细节的地方，不用模糊形容。

## 改写手法（自写）

- **删**：能删就删。推测词、升华句、排比第三项，第一动作都是删。
- **拆**：长句拆成短句，把信息塞进对话或动作。
- **换**：把判断句换成可观察的行为与物件。
- **压**：连续同构段落压掉，留一处节奏点即可。

## 复扫流程

1. 运行 `density_gate.run(text)`，按 `failures` 逐项修。
2. 运行 `prose_gate.run(text)`，`failures` 必修，`warnings` 人工判断。
3. 运行 `language_gate.run(text)`，`blocking` 清零前不得交付。
4. 改完必须**复扫**；只报告不自动改文。
