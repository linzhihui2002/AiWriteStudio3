# 去 AI 味规则与手法（human-linguistics）

## 触发条件

- 作者说「太 AI 了」「没人味」「像机器写的」。
- 章节落盘前命中去 AI 味类门禁，需要重写。
- 需要给某段文本做「人味」诊断或局部改写建议。

## 输入契约

- **待处理文本**：章节正文或局部段落。只处理正文，不动设定、大纲。
- **门禁阈值**：一律引用工作台门禁模块的常量，不在本技能硬编码数值：

| 阈值 | 引用位置 |
|---|---|
| 破折号密度上限 | `gates.density_gate.DASH_LIMIT` |
| 对话引号密度下限 | `gates.density_gate.DIALOG_MIN` |
| 禁用套话表 | `gates.density_gate.DEFAULT_FORBIDDEN` |
| 三连排比模式 | `gates.density_gate.TRIPLE_PATTERNS` |
| 硬停词与模型路标 | `gates.prose_gate` 对应常量 |

- 词表按**类别**使用，不背具体词条；类别清单与例子见 [去AI味手法与词表](references/去AI味手法与词表.md)。

## 输出契约

- **只报告不自动改文**（作者明确要求改写时才产出改写稿）。
- 诊断输出：命中类别、出现位置、建议手法（删/拆/换/压）三件事。
- 改写稿：保持情节、人物与信息不变，只改叙述方式；不新增情节。
- 复扫结论：改写后必须重跑门禁并报结果。

## 边界（做什么·不做什么）

**做**

- 按类别识别 AI 痕迹并给出可定位的修改方向。
- 提供「删 / 拆 / 换 / 压」四类手法的具体操作。

**不做**

- 不改情节、不改人物关系、不改信息量。
- 不为「像人工」而故意制造病句或错别字。
- 不把人物口语里的口语词当叙述层推测词删掉（口语吐槽要保留）。
- 不去动门禁阈值本身。
- 不处理非正文材料。

## 步骤

1. **跑门禁**：先跑密度门与散文门，拿到 `failures` 与位置；不要把门禁能判的事靠肉眼估。
2. **分类命中**：把问题按类别归档（破折号、推测词、排比、升华腔、解释癖、对话不足）。
3. **按手法改**：优先「删」；删不掉的「拆」；判断句「换」成可观察行为；同构段落「压」。
4. **复扫**：重跑门禁，阻断项清零之前不得交付。
5. **记结论**：报改前命中项、改后结果，以及仍存疑之处。

### 判断规则

- **能删就删**：推测词、升华句、排比第三项，第一动作一律是删。
- **叙述层从严、口语层从宽**：叙述里的「显然」要删，对话里角色说「显然」可能正是他的性格。
- **具体优先**：能用数字、专名、可验证细节的地方不用模糊形容词。
- **节奏优先于辞藻**：短句与动作往往比修饰语更有人味。
- **一次一类**：同一段不要同时大改三处，避免改出新问题。
- **先结构后词面**：优先修结构性问题（对话不足、同构段落），再逐个换掉具体词；顺序调换会白改。

### 分场景处理

| 场景 | 主要问题 | 处理顺序 |
|---|---|---|
| 章首 | 套话起句、环境堆叠 | 先删首句的形容词，再补一个具体动作 |
| 对话段 | 说明腔、人人同声 | 给每人固定句长与称呼，删掉解释句 |
| 叙述段 | 推测词、对仗腔 | 先删推测词，再把对仗拆成短句 |
| 章末 | 升华腔、无钩子 | 删总结句，改回动作或事实 |
| 全章 | 规整过头、段落等长 | 打散段落长度，留一两处极短句 |

### 改写自检三问

1. 这段删掉之后，信息是否还在别处？在就别留。
2. 这个判断句，能不能换成人物做的一个动作？
3. 同一段里有没有两句结构完全一样？有就拆一处。

### 按类别的处理清单

| 类别 | 识别特征 | 首选手法 | 改后确认 |
|---|---|---|---|
| 破折号顶替停顿 | 叙述中破折号密集 | 换句号/省略号 | 密度回到阈值内 |
| 对话不足 | 长段无引号 | 拆段并塞入对话 | 对话密度达标 |
| 叙述层推测词 | 「似乎/显然/大概」在叙述句 | 删，换动作 | 叙述层零命中 |
| 三连排比 | 三项同结构并列 | 留两项或改短句 | 句式模式零命中 |
| 升华腔 | 章末点题总结 | 删，改动作或事实 | 末三段无总结句 |
| 解释癖 | 动作后又解释一遍 | 删解释句 | 无重复说明 |
| 对仗腔 | 「不是……而是……」成段 | 拆成不对称短句 | 无成段对仗 |
| 模糊量词堆叠 | 「无数/万千/无尽」密集 | 换具体数字或单细节 | 量词密度下降 |
| 段落等长 | 每段句数接近 | 打散长短 | 出现一两处极短句 |

### 处理顺序与验收

1. 先修结构类（对话不足、段落等长、对仗腔），再改词面类（推测词、模糊量词）。
2. 每改一类，立即重跑对应门禁，确认该类命中清零再进入下一类。
3. 全部改完做一次通读，检查节奏：长短句是否交替、对话是否成对。
4. 若某类问题反复出现，说明是写作习惯而非局部瑕疵，在报告里提示作者注意章首与章末两个高发位置。

### 改写边界再强调

- 保留人物的口语词与方言，只动叙述层的 AI 痕迹。
- 不新增情节、不删信息；只改变表达方式。
- 宁可少改，也不要为了「去味」把句子改得生硬或不通顺。

### 章首与章末专项

**章首**（问题最集中的位置）：

1. 删掉首句的形容词与套话，直接给动作或对话。
2. 首段不要交代背景，背景放到第二段或借对话带出。
3. 首段不要出现「随着」「在这个」这类引导词。

**章末**（升华腔高发位置）：

1. 末三段逐句检查有无总结、点题、抒情收尾。
2. 收尾改回动作、事实或一句未说完的话。
3. 若末尾出现「从此」「唯有」「注定」这类词，多半是升华腔。

### 改写对照例库

| 原文 | 问题 | 改写 |
|---|---|---|
| 他缓缓抬起头，突然明白了什么 | 套话 + 下判断 | 他抬头。他知道是谁了 |
| 不是害怕，不是愤怒，不是绝望 | 三连排比 | 他不怕，也不气 |
| 仿佛整个世界都安静了 | 套话 + 模糊 | 码头上的机器停了 |
| 他显然不愿意，似乎想说什么 | 叙述层推测词 | 他张了张嘴，又闭上 |
| 这一刻，他终于明白了坚持的重量 | 升华腔 | 他把货单塞进怀里 |
| 因为他不想被看出动摇，所以他没有说话 | 解释癖 | 他没说话 |
| 无数次的失败，无数次的爬起 | 模糊量词 + 排比 | 第三次摔下来，他又站起来 |
| 屋里有种说不清的压抑，令人喘不过气 | 模糊形容 | 窗纸发霉，桌上一层灰 |

对照例只示范手法，实际改写要以本书人物与情节为准，不要照搬句式。

### 交付格式

```
【诊断】命中 3 类：破折号 7 处（行 12、40、88）、三连排比 1 处（行 55）、升华腔 1 处（末段）
【建议】破折号→句号；排比留两项；末段换动作收尾
【复扫】密度门通过、散文门通过、语言门通过
```

### 人工复核要点

门禁通过不代表读起来像人写的，最后一步要人工扫一遍：

1. 连续三段开头句式是否相同？相同就换一处。
2. 有没有「他想到……」「他想起……」这类回忆句扎堆？
3. 场景里有没有可替换成具体物件的空泛形容？
4. 人物说话的句长是否都一样？一样就拆一处。
5. 全章有没有一处「读者要靠猜」的留白？没有就删掉一句解释。

这五条不靠阈值判定，靠通读，但往往决定读感。

### 阈值引用纪律

- 本技能不写死任何数值：破折号密度、对话密度、词表、句式模式一律从门禁模块读取。
- 报告里引用阈值时写明来源（例如「密度门上限定为每 250 字 1 个」由门禁常量给出）。
- 门禁调整阈值后，本技能的判定自动跟随，无需改文本；发现文本与门禁口径不一致时，以门禁为准并报告不一致。

## 正反例

**反例 1（破折号顶替停顿）**

> 他停住了——不是因为害怕——是因为想起了那句话。

问题：破折号密集，且「不是因为……是因为……」是对仗腔。

**正例 1**

> 他停住。不是怕。那句话他听过。

**反例 2（三连排比 + 升华腔）**

> 他不是为了钱，不是为了名，不是为了复仇。这一刻，他终于明白了什么是坚持。

问题：三连排比加章末升华，两处 AI 指纹叠加。

**正例 2**

> 他缺的是那张货单。拿到手，妹妹才能回来。

**反例 3（叙述层推测词）**

> 他显然很愤怒，似乎要立刻动手。

问题：替读者下判断，全知旁白。

**正例 3**

> 他把碗推到桌沿，手背上的筋绷起来。

**反例 4（解释癖）**

> 他没有说话，因为他不想让对方看出自己其实已经动摇了。

问题：前半句动作已说明，后半句又替读者解释一遍，属于解释癖。

**正例 4**

> 他没说话。手指在桌沿上敲了两下，停住。

**反例 5（对话不足、段落等长）**

整章七段，每段都是四句话的叙述，没有一句对话。

问题：阅读节奏僵死，也没有人物声音。修法：至少插入两处对话，把其中一段压成一到两句。

## 验收清单

- [ ] 改前改后都跑过门禁，阻断项已清零。
- [ ] 破折号密度与对话密度均达标（引用门禁阈值，未凭手感）。
- [ ] 三连排比与叙述层推测词零命中。
- [ ] 升华腔与解释癖已按「删/拆/换/压」处理。
- [ ] 改写后情节、人物、信息未变。
- [ ] 人物口语中的口语词被保留，未被误删。
- [ ] 段落长度已打散，未出现通篇等长段落。
- [ ] 报告给出命中类别、位置与建议手法三件事，未只给笼统评语。
