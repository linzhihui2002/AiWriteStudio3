# 去 AI 味手法与词表（按类别）

本清单是 `human-linguistics` 的 L3 明细。**词表按类别给例，不照抄任何外部清单**；具体数值阈值以工作台门禁模块为唯一事实源。

## 一、类别清单

### C1 破折号顶替停顿

- 症状：叙述中破折号密集，用来代替句号或省略号。
- 判定：破折号密度超过门禁上限即命中。
- 修法：停顿用句号，拖音用省略号；一次对话里最多留一个破折号。
- 例：`他停了——不知道该说什么——` → `他停住。他不知道该说什么。`

### C2 对话不足（叙述堆砌）

- 症状：整段纯叙述，长时间没有引号对话，读者失去呼吸感。
- 判定：对话引号密度低于门禁下限。
- 修法：把信息塞进对话；或拆段，用短句制造停顿。

### C3 叙述层推测词

- 症状：作者替读者下判断。类别例：`似乎 / 好像 / 显然 / 大概 / 略显 / 无疑是 / 想必`。
- 判定：出现在**叙述句**即命中；出现在人物对话里按人物性格处理。
- 修法：删掉，换成可观察的动作、表情或物件。
- 例：`他显然在犹豫` → `他捏着杯子，没喝`。

### C4 三连排比

- 症状：同结构三项并列，是最稳定的模型句式指纹。类别例：`不是A，不是B，不是C`、`没有A，没有B，没有C`、`记得X，记得Y，记得Z`。
- 判定：命中即禁。
- 修法：保留两项，第三项换说法或删；也可改成两个短句。

### C5 升华腔（点题总结）

- 症状：章末或段末替读者总结意义。类别例：`这一刻 / 他忽然明白了 / 这就是……的意义 / 人生不过如此`。
- 判定：多出现在章末三段内。
- 修法：删掉总结句，改回动作或事实。

### C6 解释癖

- 症状：把已经通过动作说明的事再用一句解释一遍，或替读者补因果。类别例：`因为……所以他才……`、`也就是说`、`换句话说`。
- 判定：解释句与前面动作重复时命中。
- 修法：删掉解释句，只留动作。

### C7 对仗腔

- 症状：`不是……而是……`、`既要……又要……`这类对称结构成段出现。
- 修法：拆成不对称的短句，破坏节拍。

### C8 数量与感官堆叠

- 症状：`无数 / 万千 / 无尽`这类模糊量词密集，或一句话里堆三个以上感官形容。
- 修法：换成具体数字或单个可验证的细节。

## 二、四类手法

| 手法 | 适用 | 操作 |
|---|---|---|
| 删 | 推测词、升华句、排比第三项、重复解释 | 直接删，不加替代 |
| 拆 | 长句、嵌套从句 | 按动作切成短句 |
| 换 | 判断句、抽象形容 | 换成行为、物件、数字、专名 |
| 压 | 连续同构段落 | 压成一段，只留一个节奏点 |

## 三、误伤清单（不要删的）

- 人物口语里的推测词：`他大概不会来了`（人物在判断，是性格）。
- 方言与口头禅：属于语言习惯字段，保留。
- 必要的省略号：表现拖音与迟疑，但不要连续成串。
- 数字与专名：越具体越人味，不要为「简洁」删掉。

## 四、复扫流程

1. 跑密度门，按 `failures` 逐项修，直到 `passed`。
2. 跑散文门，`failures` 必修，`warnings` 人工判断后决定是否处理。
3. 跑语言门，阻断项清零前不得交付。
4. 全部通过后，再读一遍整体节奏：短句比例是否够、对话是否成对。
