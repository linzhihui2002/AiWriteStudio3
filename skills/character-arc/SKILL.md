# 角色成长与一致性（character-arc）

## 三个必查维度

1. **弧光有据**：心态/立场/关系值的变化，在变化前必须有至少一次可指认的铺垫（事件、对话、观察）。没有铺垫的突变 = 不通过，并指出应补铺垫的位置。
2. **性格不漂移**：言行是否符合角色卡的性格特质、说话风格（口癖/句长/称呼习惯）；如果为了剧情需要角色「不像他」，必须显式标注为作者决定，而不是默认放行。
3. **事实不越界**：角色只能知道他亲历、被告知、或可合理推知的信息。若角色说出只有别人知道的秘密且无告知情节 → 事实越界，判不通过。

## 步骤

1. 取本章涉及角色的：性格要点、当前状态（位置/伤势/心理/关系）、近期视角记忆。
2. 逐条比对正文中的言行，产出三类问题：无铺垫突变 / 性格漂移 / 事实越界。
3. 每条问题给出：角色、字段、正文证据、建议补法（在哪一章补哪一段铺垫）。
4. 需要变更状态时走收件箱提案，附旧值校验（模型必须逐字报出旧值）。

## 验收清单

- [ ] 所有判定都引用了正文证据；无证据的判「待核实」而不是「通过」。
- [ ] 突变项给出了具体补铺垫位置。
- [ ] 事实越界项说明了「该角色何时才能知道」。
- [ ] 状态变更提案包含旧值，且与台账旧值逐字一致。
