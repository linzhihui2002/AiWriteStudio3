# 角色弧光检查表

本清单是 `character-arc` 的 L3 明细，提供逐项打勾的检查表、三类问题的判定口径与证据格式。

## 一、检查前需要备齐的材料

| 材料 | 用途 | 缺了怎么办 |
|---|---|---|
| 角色卡（目标/动机/能力边界/性格/语言习惯/已知信息边界） | 判性格漂移与越界 | 判「待核实」，只做粗判 |
| 状态快照（位置/伤势/心理/关系值/最后更新章） | 判变化是否有据 | 同上 |
| 变化发生前的若干章正文 | 找铺垫 | 判「待核实：缺前文」 |
| 本章正文 | 取证据 | 无正文不评 |

## 二、逐项检查表

对本章涉及的每个角色逐项打勾：

- [ ] **目标一致**：他本章的行动是否仍服务于角色卡里的目标？
- [ ] **动机可溯**：行动背后是否有已建立的动机？还是突然冒出来的？
- [ ] **能力守界**：他做的事是否超出「能力边界」的上限？
- [ ] **语言习惯**：句长、称呼、口癖是否与卡一致？
- [ ] **处事方式**：遇事的反应方式是否与既往一致？
- [ ] **关系方向**：与他人的关系值是否只发生了有铺垫的渐变？
- [ ] **信息合规**：他提到的信息是否来自亲历、被告知或可合理推知？
- [ ] **状态承接**：位置、伤势、随身物是否接得上状态快照？

任一项不满足：先查是否有铺垫，再决定归类。

## 三、三类问题的判定口径

### A 无铺垫突变

- 定义：心态/立场/关系在变化前，至少一次可指认的铺垫（事件、对话、观察）不存在。
- 判定：回溯变化前全文检索相关线索，无命中即成立。
- 输出：变化内容、发生章、涉及字段、建议补铺垫的章与段落。

### B 性格漂移（OOC）

- 定义：语言习惯、处事方式、性格特质三项中至少两项偏离角色卡。
- 判定：只偏离一项时，标「轻微偏离」并说明；不直接判 OOC。
- 例外：作者有意安排的角色转变，标注为「作者决定」，不作为问题。
- 输出：角色、字段、正文证据、应保持或应更新的角色卡字段。

### C 事实越界

- 定义：角色掌握了未亲历、未被告知、也不能合理推知的信息。
- 信息三来源：亲历（在场）、被告知（有告知情节）、可合理推知（有依据的推理）。
- 输出：越界的具体信息、该角色当前不该知道的理由、补告知的章与方式，或改为推测句的写法。

## 四、证据格式

统一为：

```
角色 ｜ 问题类型 ｜ 涉及字段 ｜ 正文证据（章号 + 摘句 ≤20 字） ｜ 建议补法
```

判定「通过」也要给证据（例如「语言习惯与卡一致，见第0031章『你少废话』」），否则记「待核实」。

## 五、判定阈值速查

| 项 | 阈值 |
|---|---|
| 突变判定 | 变化前 0 次铺垫即成立；1 次以上视为有据 |
| 性格漂移 | 三项中 ≥2 项偏离 |
| 关系变化 | 需要有铺垫章，且变化幅度与铺垫分量相称 |
| 事实越界 | 三来源全不满足 |

## 六、常见误判

| 误判 | 说明 |
|---|---|
| 把作者设定转变当 OOC | 先确认是否作者决定 |
| 把角色成长当突变 | 成长有连贯铺垫则成立 |
| 把合理推理当越界 | 有依据的推理不算越界 |
| 把一次性失态当漂移 | 需 ≥2 项偏离才判漂移 |
| 把「性格标签」当全部 | 仍要看语言与处事两项 |
