# 设定字段规范

本清单是 `novel-setting` 的 L3 明细，字段按此填，不要自创字段名。每张卡末尾都要有「来源」与「依据」两栏。

## 通用规则

- **一卡一对象**：一个角色、一个势力、一条世界规则各占一张卡。
- **对象与字段分层**：对象用标题，字段用分行条目；表格若第一列为「字段/项目」，各行归入所属对象，不能当成独立对象。
- **来源放行尾**：如 `- 身份：据点跑货人。（来源：author）`。字段值不整段加粗；未知值写「待确认」并保留 unknown 来源。
- **字段可空但要显式**：暂时不知道就写「待核实」，不要留空让读者猜是漏了还是不知道。
- **每条事实带依据**：格式统一为 `（依据：第NNNN章 简短定位）`，定位到段落级即可，不抄原文。
- **来源三级**：`author`＝作者直接给的；`model`＝从正文提炼的；`unknown`＝无法判定。审稿时 `unknown` 一律按待核实处理。

## 人物卡必填字段

| 字段 | 写法要求 |
|---|---|
| 姓名/正式名 | 全文唯一，别名另列 |
| 别名/称呼 | 谁在什么场合怎么称呼他，含绰号与旧称 |
| 身份 | 当前社会身份，不是履历；变化要写「第NNNN章起改为…」 |
| 目标 | 他想要什么，可验证（「攒够三十两」而不是「想变强」） |
| 动机 | 为什么想要，指向具体的人或事 |
| 能力边界 | 会什么、到什么程度、打不过谁。**必须写上限**，否则后续战斗无约束 |
| 关系 | 与主要角色的关系与关系值方向（亲近/利益/敌对） |
| 语言习惯 | 句长、口癖、称呼习惯、是否用敬称 |
| 已知信息边界 | 截至当前章他知道什么、不知道什么；谁知道他不知道 |
| 状态锚点 | 位置、伤势、随身物，指向 `状态/角色状态.md` |
| 来源/依据 | 见通用规则 |

## 世界规则卡必填字段

- **规则陈述**：一句话说清规则本身。
- **适用范围**：谁、在哪里、什么时候生效。
- **代价/限制**：这条规则要付出什么，缺了代价的规则会变成万能设定。
- **例外**：已知的破例情况与条件。
- **首次出现**：章号与依据。
- **来源**。

## 势力卡必填字段

名称、性质（门派/商会/官面/流民）、当前目标、资源与地盘、内部派系与矛盾、与主角的关系方向、首次出现章、来源。

## 物品与技能卡必填字段

- **物品**：名称、来历、当前持有人、当前所在地、关键属性与限制、首次出现章、来源。
- **技能/功法**：名称、来源、境界或等级对应、能做什么、代价与冷却、已知掌握者、首次出现章、来源。

## 场景卡必填字段

地名、地理关系（与哪些地点相邻、路程）、气候与地貌、当地势力、在故事里的功能（主场/中转/禁地）、首次出现章、来源。

## 来源分级的标注格式

在卡片末尾或字段行尾，用如下形式：

```
来源：author（作者在第 12 次对话中确认）
来源：model（依据：第0007章 被压制）
来源：unknown（正文只提到一次，无法判断是否长期有效）
```

`unknown` 的字段在后续章节里一旦拿到依据，必须在同一轮把来源升级为 `model` 或 `author`，不要长期挂着。

## 修改已有条目的要求

1. 改前先读旧条目原文。
2. 提案中逐字报出旧值与新值，便于作者比对。
3. 旧值对不上时直接报「旧值不一致」，停下来问，不要按记忆里的版本改。
