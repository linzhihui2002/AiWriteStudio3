# 章节审稿（novel-review）

## 定位

只做**验收与报告**，不改稿。修改由写作者按报告执行，避免审稿人替作者做决定。

## 三态判定（核心原则）

| 状态 | 含义 | 是否算通过 |
|---|---|---|
| 通过 | 有可复现的证据（门禁输出 / 原文行号）支撑 | 是 |
| 待改 | 命中硬门禁，必须修改 | 否 |
| 待核实 | 无法用现有材料判定（缺大纲、缺设定、缺上下文） | **否** |

**待核实一律不算通过。** 不得用「看起来没问题」「大致符合」把待核实项
转写为通过；无法判定就如实标注缺什么材料。

## 验收清单（逐项，不得跳项）

1. **字数门**：正文汉字数 ≥ 2000。汉字计数只统计 `\u4e00-\u9fff`，不含标点与空白。
2. **语言门**：正文必须为中文散文。
   - HTML 标签 / 注释 / 实体：一律阻断，零容忍。
   - 外语字母 token：阻断；确需逐字保留的，必须有用户单独确认并已精确登记。
3. **禁词门**：破折号 ≤ 每 250 字 1 个；对话引号 ≥ 每 120 字 1 次；禁词表零命中。
4. **去 AI 味门**：三连排比全禁；叙述层推测词零容忍。
5. **章节衔接**：开头不得复述上一章结尾；结尾钩子必须有人回应。
6. **待核实项**：逐条列出缺失材料（如「未提供细纲，无法判定情节是否越界」）。

## 门禁调用

阈值与词表的唯一事实源在 `workbench/backend/gates/`，审稿时直接 import 调用：

```python
from workbench.backend.gates import density_gate, language_gate, prose_gate

density = density_gate.run(text)     # 破折号 / 对话密度 / 禁词 / 三连排比
prose = prose_gate.run(text)         # 硬禁令与模型化形状（failures 为必修项）
language = language_gate.run(text)   # HTML 阻断 + 外语泄漏
```

三者的 `passed` 均为真、且字数门达标，才可判「通过」。

## 输出格式

```
结论：待改（2 项）
[待改] 破折号 7 个，红线为每 250 字 1 个（第 12、40、88 行）
[待改] 命中禁词：突然 ×2、仿佛 ×1
[通过] 语言门：无 HTML、无外语泄漏
[待核实] 未提供分卷大纲，无法判定本章是否提前释放第 3 章钩子
```

每条结论必须附**可复现证据**（行号 / 计数 / 门禁字段名）。
