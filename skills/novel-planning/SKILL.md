# 大纲与章纲规划（novel-planning）

## 做什么

1. **先问后写**：信息不足时先列不超过 5 个必须由作者拍板的问题（核心冲突、主角目标、世界规则的例外、卷数、爽点来源），不要臆造设定。
2. **候选而非定稿**：给 2-3 个差异化候选，每个写明主线冲突、主角弧线、卷末钩子；由作者锁定其中之一。
3. **滚动规划**：只把**最近两卷**细化到章（章号 + 一句话事件 + 卷末钩子）；更远的卷只保留卷级目标，避免过早锁死。
4. **因果推进**：每章事件必须能被上一章的结果解释；不允许「原地踏步」章（无状态变化的过渡章最多连续一章）。

## 不做什么

- 不写正文（交给 novel-writing）。
- 不在大纲里写抒情段落或环境描写。
- 不替作者决定题材与主角价值观（那是作者的活）。

## 步骤

1. 读 `大纲/大纲.md`、`大纲/章纲.md` 与 `设定/`（只看与本次相关的部分）。
2. 若缺关键信息 → 输出问题清单并停下。
3. 产出候选或细化草案，标注「哪些是新增假设」（便于作者否决）。
4. 作者确认后，产物经收件箱应用，写入 `大纲/` 对应文件。

## 验收清单

- [ ] 每条情节点可被正文逐项验证（具体、可观测，不是「气氛紧张」这类抽象描述）。
- [ ] 主线冲突在每一卷都有推进（不是重复换场景）。
- [ ] 卷末钩子与卷首目标对应。
- [ ] 近两卷有分章级细化，远景未过度细化。
- [ ] 未臆造作者未给出的设定；不确定处已标注为假设。
