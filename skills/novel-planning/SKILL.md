# 大纲与章纲规划（novel-planning）

## 触发条件

- 作者要求从零列大纲，或把现有主线扩成卷纲、章纲。
- 作者问「接下来写什么」「这一卷怎么收」「剧情怎么走」。
- 写作前需要确认某章的章纲（情节点、钩子）是否已经冻结。
- 正文推进后，需要把后续章纲按已发生的事实回填或调整。

## 输入契约

- **已有材料**：`大纲/大纲.md`、`大纲/章纲.md`，以及与本次相关的 `设定/`（只读，不写）。
- **作者已定的信息**：核心冲突、主角目标、卷数、爽点来源、题材基调。这些**只能由作者给**，不得臆造。
- **当前进度**：已完成到第几章，最近一次章纲冻结到哪。
- 信息不足时：先输出不超过 5 个必须由作者拍板的问题，然后停下等待，不要先写一版猜的。

卷与章的字段定义、卷末钩子要求、远近景边界见 [大纲结构规范](references/大纲结构规范.md)。

## 输出契约

- **候选而非定稿**：至少给 2 个差异化候选（主线冲突、主角弧线、卷末钩子各不相同），由作者锁定其一。
- **分卷结构**：每卷写清卷级目标、主要冲突、结尾钩子；近两卷细化到章。
- **章纲**：每章一行，含章号、一句话事件、状态变化、章末钩子类型。
- **假设清单**：凡是为推进而补充的设定，单列「新增假设」，便于作者否决。
- **结账行**：`新增假设 N 条 / 细化到第 M 章 / 悬置问题 K 个`。

## 边界（做什么·不做什么）

**做**

- 把模糊灵感翻译成可执行的分卷与章纲；指出主线冲突在哪一卷推进。
- 给出候选方案与取舍理由，标出每章的因果链。
- 把信息缺口整理成问题清单。

**不做**

- 不写章节正文、不写大段抒情或环境描写（归 novel-writing）。
- 不改 `设定/`、`状态/`、`章节/`；需要新设定时只在假设清单里提出，由作者决定是否另起一轮。
- 不替作者决定题材与主角价值观。
- 不把远景卷细化到章，避免过早锁死。
- 不在信息不足时先产出「凑数版」大纲。

## 步骤

1. **读**：现有大纲与章纲，扫一遍相关设定，只看与本次相关的部分。
2. **问**：列出必须由作者拍板的问题（不超过 5 个），缺信息就停在这一步。
3. **立骨架**：先定主线冲突与主角弧线的起承转合，再切卷；每卷一个明确的卷级目标。
4. **落近景**：把最近两卷细化到章，逐章写明事件、状态变化、章末钩子。
5. **查因果**：逐章检查「本章事件能否被上一章的结果解释」，删掉原地踏步的过渡章。
6. **出候选**：给出 2 个差异化候选，列明假设清单，等作者锁定。
7. **交付**：作者确认后走收件箱，写入 `大纲/` 对应文件；未确认前不落盘。

### 判断规则

- **卷是目标单位**，章是事件单位：卷末必须回答「这一卷的目标达成了吗」，章末只回答「这一章发生了什么变化」。
- **一章一变**：每章至少推进一种状态（实力、关系、信息、资源），四种都不动的章节要么合并要么删。
- **钩子不重复**：连续两章不要用同类型的钩子（都用「神秘人来访」读者会疲劳）。
- **远景粗化**：只写卷级目标与大致走向，不写具体章号，给后续留改的余地。
- **假设显式**：任何作者没说的设定都写进假设清单，标注「未获确认」。
- **回填优先于重写**：正文已推进的部分以正文为准，只调整后续章纲，不回改已写章节。
- **一卷一个主要冲突**：卷内可以有支线，但同一时间只能有一条主导矛盾，否则读者注意力散掉。
- **钩子类型轮换**：连续两卷不要用同型钩子；信息型、威胁型、机会型、关系型交替使用。

### 交付与确认流程

1. 骨架（核心冲突 + 主角弧线）→ 请作者确认，锁定后才切卷。
2. 卷级方案（2 个候选）→ 作者选一，或指出要合并的部分。
3. 近两卷章纲 → 作者逐章否决个别章，改完再冻结。
4. 冻结后才可作为写作合同，交由 novel-writing 使用；未冻结的章纲不写正文。

### 章纲字段速查

```
第NNNN章 ｜ 事件 ｜ 状态变化 ｜ 章末钩子类型 ｜ 因果
```

- **事件**：动词短语，一句话，写「谁做了什么」，不写「气氛如何」。
- **状态变化**：实力、关系、信息、资源四项至少一项，且必须能被后续章节验证。
- **章末钩子类型**：行动 / 信息 / 威胁 / 关系，四选一。
- **因果**：写「接第NNNN章的什么结果」。指不回去，说明这一章凭空插入，要补铺垫或删掉。

### 候选方案的写法

1. 两个候选的主线冲突不能只换皮，要换「谁和谁对立」或「为什么对立」。
2. 每个候选附**代价**：选它之后哪些写法被排除，方便作者取舍。
3. 候选都要能给出一条完整的卷末钩子链；缺链的候选直接淘汰。
4. 候选之间至少在「主角弧线」上有一处实质不同，否则只是同一方案的两版措辞。
5. 作者锁定其一后，未选中的候选留在报告里备查，不要删档。

### 回填规则（正文推进后）

1. 已写完的章节以**正文为准**回填章纲，结账行列明改动的章号。
2. 回填后检查后续三章的因果是否被破坏，破坏的一并调整。
3. 回填只改章纲文本，不得改动已写正文。
4. 若正文偏离了原卷级目标，先把偏差写进报告，由作者决定修目标还是修后续。

### 信息不足时的提问清单

1. 核心冲突是谁和谁因为什么对立？
2. 主角的起点状态与终点状态分别是什么？
3. 计划几卷，每卷大致处理哪个阶段？
4. 爽点主要来自哪一类（打脸 / 升级 / 布局 / 夺宝）？
5. 有没有已经定死、必须保留的情节节点？

缺其中任意一项，都先停下等回答，不写「凑数版」大纲。

### 每卷交付前自检

1. 卷级目标是否可验证（能回答「达成了吗」）？
2. 主要冲突是否与上一卷不同，还是换了场景重复？
3. 卷末钩子是否指向下一卷目标，且在本卷有过铺垫？
4. 近两卷的每一章是否有状态变化，有无连续过渡章？
5. 远景卷是否只写到卷级，没有提前锁死章号？
6. 假设清单是否覆盖了本轮所有作者未给的信息？

任一项否，回到对应步骤重做，不要靠措辞掩盖。

### 与其他技能的衔接

- 需要新设定支撑大纲时，只在假设清单里提出，不直接写 `设定/`。
- 章纲冻结后交 `novel-writing` 当写作合同；章纲变更要通知写作者按新版执行。
- 正文已推进的偏差，用回填规则处理，不改已写章节。
- 情节是否越界由 `novel-review` 在审稿时对照本章章纲判定。

### 常见返工原因

| 返工原因 | 根因 | 预防 |
|---|---|---|
| 卷末钩子对不上卷目标 | 定钩子时没回看目标 | 每卷末尾检查钩子指向 |
| 章纲锁死远景 | 提前细化 | 远景只写卷级 |
| 正文推进后大改章纲 | 没做回填 | 每卷完结做一次回填 |
| 作者否决整版方案 | 臆造设定 | 假设全部列入清单 |

## 确定性校验（只报告不改写）

大纲与章纲的机械部分交给门禁跑，结论原文报出，不自行补齐章号、不臆造钩子：

- **章号与钩子**：调用对话工具 `check_tracking`（`target="大纲"`，默认校验 `大纲/章纲.md`），或 `gates/outline_gate.py` 的 `run`——章号重复为 error（判失败），跳号 / 回退与「有卷末钩子缺卷首目标」（或反之）为 warn，章号后缺一句话事件也报出。
- **结账行**：把 `run` 返回的 `detail`（共 N 章、重复 X 处、跳号 Y 处、缺事件 Z 处、钩子目标缺对 W 处）并入结账行，标为待作者处理的项。

## 正反例

**反例 1（抽象不可验证）**

> 第0018章：气氛紧张，主角感到压力，局势一触即发。

问题：没有事件、没有状态变化、无法在正文里逐项验证。

**正例 1**

> 第0018章：沈砚在码头等到深夜，货船被官船扣下（信息：货主涉私盐）｜变化：他失去这批货，欠债到期｜钩子：他决定去官仓偷货单｜因果：接第0017章交货被拒。

**反例 2（过早细化）**

> 第0050章…第0080章 全部写出了具体事件。

问题：远景锁死，后续正文推进后必须大改。

**正例 2**

> 第三卷（约 45-70 章）：主角进入郡城势力圈，卷级目标是拿到盐引；具体章纲待第二卷完成后细化。

**反例 3（臆造设定）**

作者只说了「小镇少年想出头」，大纲里直接写「他的父亲是隐世剑圣」。

问题：凭空捏造作者未给的信息。应改为假设清单里的一条，标注未确认。

**反例 4（钩子重复）**

连续三章结尾都用「神秘人出现」。

问题：钩子同型会造成读者疲劳，也说明冲突没有真正推进。

**正例 4**

> 第0017章（信息型）：货单上有个他认识的名字。\n第0018章（行动型）：他决定去官仓偷货单。\n第0019章（关系型）：老周不再叫他小沈。

## 验收清单

- [ ] 每条情节点具体可观测，能被正文逐项验证。
- [ ] 主线冲突在每一卷都有实质推进，不是换场景重复。
- [ ] 每章至少有状态变化中的一项，无原地踏步章（过渡章最多连续一章）。
- [ ] 卷末钩子与卷级目标对应。
- [ ] 近两卷细化到章，远景只到卷级，未过度细化。
- [ ] 未臆造作者未给出的设定；补充信息全部列入假设清单。
- [ ] 产物经作者确认后走收件箱，未静默写盘。
- [ ] 每卷只有一条主导冲突，支线未压过主线。
- [ ] 连续章/连续卷未使用同型钩子。
