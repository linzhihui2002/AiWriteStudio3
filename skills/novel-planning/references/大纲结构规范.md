# 大纲结构规范

本清单是 `novel-planning` 的 L3 明细，规定 `大纲/大纲.md`（卷级）与 `大纲/章纲.md`（章级）的字段与边界。

## 一、全书级

只写三样，不超过半页：

1. **核心冲突**：一句话，说明谁和谁因为什么必然对立。
2. **主角弧线**：起点状态 → 终点状态，中间至少三次转折的概述。
3. **爽点来源**：作者指定的主要爽感类型（打脸 / 升级 / 布局 / 夺宝…），后续每卷都要能对上。

## 二、卷级字段（`大纲/大纲.md`）

每卷一个块：

```
## 第N卷 卷名
- 卷级目标：这一卷结束时主角要拿到/改变什么（可验证）
- 主要冲突：本卷的对立面是谁，为什么躲不开
- 起点状态 / 终点状态：卷首与卷末的主角处境
- 主要事件节拍：3-6 个，按因果排序
- 卷末钩子：类型 + 一句话内容
- 涉及材料：本卷会新增/修改哪些设定与状态
```

卷末钩子要求：

- 必须与**下一卷的卷级目标**相接，不能只是「出现一个神秘人」这种无指向的悬念。
- 类型要轮换：信息型、威胁型、机会型、关系型，连续两卷不要同型。
- 钩子必须在卷内有过铺垫，不能凭空冒出来。

## 三、章级字段（`大纲/章纲.md`）

每章一行，字段固定：

```
第NNNN章 ｜ 事件（一句话） ｜ 状态变化（实力/关系/信息/资源，至少一项） ｜ 章末钩子类型 ｜ 因果（接哪一章的什么结果）
```

写法要求：

- **事件**用动词短语，写「做了什么」而不是「气氛如何」。
- **状态变化**至少写一项，且要能被后续章节验证。
- **章末钩子**写类型，不写具体台词。
- **因果**必须指回上一章的具体结果；指不回去就说明这一章是凭空插入的，需删或补铺垫。

## 四、近景细化与远景粗化的边界

| 范围 | 细化程度 | 允许写的内容 |
|---|---|---|
| 最近两卷 | 细化到章 | 完整章纲字段，含钩子类型 |
| 更远 | 只到卷 | 卷级目标、主要冲突、大致走向 |
| 全书 | 骨架 | 核心冲突、主角弧线、爽点来源 |

硬性边界：

- 远景**不得**写具体章号与具体事件，否则正文推进后必然大改。
- 近两卷细化完成后，若与已写正文冲突，以正文为准，回改章纲并在结账行说明改了哪几章。

## 五、常见失败模式

| 现象 | 问题 | 修法 |
|---|---|---|
| 章纲全是抽象形容词 | 无法验证 | 换成可观测事件 |
| 连续过渡章 | 节奏拖沓 | 合并或删，最多留一章 |
| 卷末钩子与卷目标无关 | 读者失去方向 | 重写钩子，指向下一卷目标 |
| 假设当事实写进大纲 | 作者不认账 | 移入「新增假设」清单并标注未确认 |
| 远景写到章 | 后续必须重写 | 回退到卷级 |

## 六、字段留空与占位规则

- 卷级字段可以留空，但要写「待定：<缺什么>」，不要留白让人以为遗漏。
- 章纲未冻结的行加 `[未冻结]` 标记；冻结后去掉标记，避免拿未冻结章纲当写作合同。
- 章号连续且唯一：跳号或重号要在结账行报出，不自行补齐。
- 同一章出现两个版本时，保留较新版本并在备注里写「替代第 N 版」，旧版不删，便于回溯。
