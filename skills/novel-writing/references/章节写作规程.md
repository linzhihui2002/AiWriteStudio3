# 章节写作规程

本清单是 `novel-writing` 的 L3 明细，讲三件事：怎么写（场景—动作—对话）、写到什么程度（字数与门禁口径）、怎么收（章末钩子收束）。

## 一、场景—动作—对话的写法

### 场景

- 只写**本章需要的**环境信息，且要服务于人物动作。写潮水是因为他要等船，不是为了展示文笔。
- 用可感知的细节（声音、温度、手上碰到的物件），不用概括性形容。
- 场景切换给一个锚点（时间或地点变化），不要在同一段里跳两个地方。

### 动作

- 动作承担信息：他摸口袋、他把饼掰开，都比「他有些犹豫」更能说明问题。
- 一段里动作不宜超过三个，多了就像镜头乱切。
- 用具体动词，少用「转身/抬头/缓缓」这类高频套话堆叠。

### 对话

- 对话用中文引号，成对出现；一段里的引号要配对。
- 每句对话至少做一件事：交换信息、暴露立场、施加压力、掩饰真实想法。
- 人物各有语言习惯：句长、称呼、是否用敬称、口头禅。同一场对话里两个人不应听起来像同一个人。
- 允许沉默和答非所问，它们比长篇解释更像真人。
- 避免「他说」「她问」连续重复，可用动作代替提示语。

### 节奏

- 长句与短句交替。紧张处用短句，交代处可稍长。
- 连续三段同构的叙述（比如都是「他想到……他想到……」）要拆开，留一处节奏点即可。

## 二、字数与门禁口径

- **字数**：以本书配置的区间为准，只统计正文汉字（不含标点、空白、数字与拉丁字母之外的符号）。低于下限直接拒收，高于上限仅告警。
- **语言**：必须是中文散文。HTML 标签、注释、实体一律阻断；外语token须经作者单独确认并精确登记。
- **禁用套话**：起句不要用「突然 / 忽然 / 仿佛 / 只见 / 缓缓」这类词。
- **破折号与对话密度**：以工作台门禁的阈值为准，不要凭手感判断。
- **三连排比**：形如「不是 A，不是 B，不是 C」的句式全禁；双项可以，第三项换说法或删。
- **叙述层推测词**：「似乎 / 显然 / 大概 / 略显」这类词在叙述层零容忍。
- 交付前跑一遍工作台门禁，任何阻断项都必须改到通过。

## 三、章末钩子的收束方式

钩子类型与写法对应：

| 类型 | 收束方式 | 例（结构示意） |
|---|---|---|
| 行动型 | 人物做出一个具体决定并开始执行 | 他收起货单，往官仓走 |
| 信息型 | 抛出一条改变处境的新信息 | 名单上有个他认识的名字 |
| 威胁型 | 出现一个明确指向他的威胁 | 巷口有人等了他很久 |
| 关系型 | 关系发生不可逆的转向 | 对方不再叫他哥 |

收束规则：

1. 钩子必须用**动作或事实**给出，不能靠作者的总结句。
2. 钩子与合同声明的类型一致；类型不对就是没写完。
3. 不做全文总结、不点题、不预告下一章标题。
4. 钩子不能凭空出现：形成钩子的要素要在本章内至少出现过一次。

## 四、常见失败模式

| 现象 | 问题 | 修法 |
|---|---|---|
| 开篇复述上章结尾 | 读者跳读 | 直接进场景，只在需要时提一句结果 |
| 人物人人伶牙俐齿 | 面孔模糊 | 给每人固定句长与称呼习惯 |
| 对话全是说明 | 信息倾倒 | 拆成问答与动作，留信息缺口 |
| 章末总结升华 | 出戏 | 换成动作或事实钩子 |
| 字数不够靠注水 | 触发密度门 | 补一段有推进的场景或对话 |
| 情节节点错位 | 越界 | 先停下报冲突，不自行改合同 |
