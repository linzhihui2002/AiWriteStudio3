# 章节正文写作（novel-writing）

## 前置条件（缺一不可）

1. **章节合同已冻结**（情节点、字数预算、钩子类型、涉及实体）；未冻结时先请作者生成并确认。
2. **上下文包已组装**：必读集（前章末 500 字 + 角色状态卡）+ 合同 + 相关设定。
3. 输出目标：草稿区（`.workbench/drafts/`）→ 收件箱 → 作者应用后才是正文。

## 硬约束（违反即失败）

- 只写正文：不写标题、不写创作说明、不写「以下是」这类引导语。
- 不堆破折号；不写「不是……而是……」对仗句式。
- 不用「突然 / 忽然 / 仿佛 / 只见 / 缓缓」这类套话起句。
- 对话用中文引号；人物说话要有信息差与个性，不要人人伶牙俐齿。
- 不用「他知道 / 她明白」这类全知旁白替代动作与细节。
- 章末落在合同指定的钩子类型上，不做全文总结。

## 步骤

1. 读合同与必读集，确认本章要接住的上一章遗留点（必须承上）。
2. 按情节点顺序写，每段落承担一个可识别的推进（动作、信息、关系变化）。
3. 自检：字数在预算 ±15% 内；硬门禁无命中；章末钩子成立。
4. 产物交收件箱，**不自动应用**。

## 验收清单

- [ ] 合同情节点全部落地（可逐项在正文中找到证据）。
- [ ] 字数门（≥2000 字）与禁词门、密度门全部通过。
- [ ] 无规划记号泄漏（情节点编号、字数预算、任务指令）。
- [ ] 章末钩子与合同一致，未提前消费后续情节点。
- [ ] 产物路径正确（草稿区 → 收件箱），正文文件未被静默改写。
