## 浏览器验收

浏览器验收使用 `.workbench/chat-acceptance` 中的隔离测试书与设置，通过真实 vendor dsh 原生接口连接本地确定性模型适配器。没有向正式书稿发送测试任务或修改正式书稿；这些结果验证集成行为，不代表已对真实远端模型的创作质量作评估。

- **批准与刷新**：批准前不写入；刷新后恢复同一批准卡；批准后原任务继续并产生实际变更记录。
- **问答与长等待**：验证单选、多选、“其他”为空时禁止提交；选择“修仙”“搜打撤”并填写“李长歌”后，结构化答案持久保存，原任务继续。等待超过原 45 秒执行超时后仍可正常回答。
- **记忆与来源**：已确认姓名显示来源消息，来源可定位；在面板更正姓名后，新对话上下文使用新值并显示 `.meta/chat-memory.json` 和作者编辑来源。
- **真实增量**：一次慢速响应在完成前观察到 41 次正文增长；标题任务在正文结束后仍能更新，并支持“AI 重新命名”。
- **后端重启**：问题等待期间终止并重启隔离服务；卡片显示中断、禁止旧提交，保留历史。点击继续后使用同一原生会话并完成任务。
- **文件冲突与撤回**：隔离设置关闭自动保存以保留未保存草稿，验证外部修改提示、保留编辑内容、采用外部版本以及撤回后恢复原文件。
- **无效自动附件**：测试选中文件缺失时显示附件提示；通过接口确认作者原文仍保存且任务完成，测试文件随后恢复。

### 已知限制（与本次验收相关）

- 关键词快路径通过「依据介词 / 位置限定」也能返回 `read_only_refs`，但与 LLM 路径的结果可能不同；未配置可用模型 / API Key 时判定退化为关键词 / 回退，评测时须一并记录 `source`。
- 多步计划采用「逐步调用 `runtime().stream()`」实现，步骤之间只靠前序产出材料落盘接力，不共享模型会话上下文。
- `chief-editor` 兼容保留作路由咨询：会话未钉住它时会被换回 `writing-assistant`。
