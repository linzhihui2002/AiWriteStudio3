# 状态功能梳理与知识同步验收（2026-10-04）

## 范围与结论

本轮检查章节、角色与追踪材料、伏笔、合同/大纲冻结、质量债、管线/工作流及知识候选状态的实际消费者。重点要求是：章节进入「完成」「发表」后，本书知识库必须实际更新，状态不能只作为界面标签。

原有章节状态已参与正文检索、前章末和历史摘要过滤，但基础索引自动更新依赖语义知识库启用开关。另发现发表态导出遗漏、旧四件套与摘要未完整核验来源、专用对话工具绕过知识生命周期投影。修复后的基础索引随作者材料维护；模型提取和审核仍保留独立流程。

## 状态消费者

| 状态功能 | 实际应用 | 相关实现 |
|---|---|---|
| 章节：草稿 / 完成 / 发表 | 编辑器修改 `chapters`；知识库只收历史定稿正文；前章末、摘要、重复表达历史、发布导出均消费资格 | `chapter_service`、`knowledge_service`、`context_service`、`prose_history_service`、`publish_service` |
| 角色状态 | `状态/角色状态.md` 注入上下文第5级，字段修订生成完整差异；来源有依据的四件套状态修改须作者应用 | `character_service`、`context_service`、`proposal_service` |
| 时间线 / 资源账本 / 伏笔记录 | 摄取提交持久化本章托管记录，供连续性检索、图谱及追踪校验使用；源章资格或版本失效时停止投影 | `ingestion_service`、`ingestion_commit`、`ingestion_records`、`knowledge_service` |
| 伏笔：计划 / 已埋设 / 已回收 | 影响标签、待回收统计、历史资格和确认操作；计划伏笔不能直接确认回收 | `bible_service`、`ingestion_service`、`knowledge_lifecycle` |
| 合同 / 大纲冻结 | 实际参与产章前置门禁；冻结后修改须确认差异 | `contract_service`、`outline_service`、`pipeline_service` |
| 质量债：open / resolved / waived | 审稿页可处理；未解决质量债进入发布自检 | `review_service`、`publish_service` |
| 管线 / 工作流步骤状态 | 持久化检查点，决定阻断、续接、已完成步骤复用和中断恢复 | `pipeline_service`、`workflow_service` |
| 知识候选：pending / staged / applied / stale 等 | 影响待审核列表、依据核验、提案生成、提交凭据补账和图谱展示 | `knowledge_candidate_service`、`knowledge_lifecycle`、`proposal_service` |

未发现 `character_service.memory_digest()` 和 `character_state_summary()` 在生产链路中的直接消费者；前者已有测试调用。角色状态原文和角色记忆文件已有读取/检索途径，但不能据此声称这两个摘要辅助函数已参与生成。章节枚举只有草稿、完成、发表；审稿「待核实」「通过」属于审稿项或审稿结果，不能与章节状态混用。

## 本轮修复的行为

1. 基础词法知识和图谱自动维护，不再要求先启用向量模型。草稿转完成/发表排队建立实际文档和片段；回退草稿立即退出历史材料，后台清理旧投影。
2. 已定稿正文改写或标题修改触发知识更新。打开已有项目核对外部编辑；中断的基础任务可恢复。未启用语义配置时跳过模型解析，保留原偏好，不触发下载、云嵌入或 AI 自动审核。
3. 四件套正式摄取只接受完成/发表章节，开始、提交、状态提案应用及重提均核验资格和正文版本。
4. 最新摄取凭据决定 `wb-ingest` 托管记录是否可作为历史。章节撤回或改稿时屏蔽旧记录，保留作者原文件和人工确认内容；普通自由材料维持原有行为。
5. `kb_documents.projection_hash` 与原文件 hash 分开，避免源章已变化而追踪文件字节未变时复用旧索引。证据仍携带原文件 hash 和原文精确跨度；分块不会横跨被屏蔽的元数据。
6. 有摄取凭据的摘要必须匹配源 hash 和已提交摘要值。没有凭据的旧手工摘要暂兼容定稿资格，无法证明其正文版本，列为限制。
7. 专用设定、角色状态、伏笔对话读取与自动上下文共用生命周期及摄取投影。作者显式读取原文件仍能核对原材料。
8. 发布筛选把完成/发表都视为已定稿；发表章节不再因发表状态被过滤或标为未定稿，字数及质量债等独立检查仍然有效。知识页显示实际中文章节状态，导出复选框文案同步。导出文件不等于实际发表，不自动改章节状态。
9. AI候选也使用追踪投影，待审/待应用依据在源章撤回、改稿或删除后失效，不能仅凭追踪文件字节未变继续应用；图谱待审覆盖层同步退出。含摄取块的缓存加入投影版本，保留普通章节的分块增量缓存及作者已应用知识。
10. 目标章明确时过滤同章/后章摄取记录。后台任务收尾与解除运行登记在同一锁内完成；新状态请求能启动新任务，旧任务收尾不能误清新任务登记。

基础索引是后台任务：状态修改接口成功表示作者状态已保存，知识页面根据实际任务和片段显示待索引、已索引或错误。普通知识同步不会直接生成四件套，也不会把未经作者审核的模型建议确认为历史事实。
