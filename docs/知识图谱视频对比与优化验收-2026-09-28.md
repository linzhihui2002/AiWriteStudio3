# 知识图谱视频对比与优化验收

本次依据作者放在仓库根目录的两段视频调整知识库体验：

- `知识图谱 - 002_开局撤离修仙界，我靠搜刮成仙 - TraeCode CN 2026-09-28 14-21-59.mp4`（42.94 秒）。
- `AI 小说创作工作台 - Tabbit 2026-09-28 14-23-20.mp4`（16.18 秒）。

仅参考交互表现，不引入对方源码、提示词或小说内容。未增加运行依赖；图谱继续使用已登记的 Cytoscape.js。

## 视频观察与复现

第一段视频中，选择文件后能看到对应的不同类型实体及连线，右侧同步列出相关节点及说明。文件分类、图谱和相关条目形成连续浏览流程。

第二段视频中，大纲主要显示为原文片段方块；人物设定仅出现文档和两个片段节点；选中物品文件后自动放大，标签明显重叠。右侧一直停留在检索引导，没有提供所选材料的内容摘要；浅色连线在缩小后几乎不可见。

本地真实项目 10（视频中的书）在修复前有 9 份已索引材料、51 个片段、82 个总节点和 188 条总边。默认去掉片段后为 31 个节点、67 条边。人物、势力、场景和伏笔节点均为零。代码审计发现：

1. 设定解析只匹配二至四级标题，漏掉该书合法的一级卡片标题；编号伏笔列表也未被解析。
2. 来源只查元数据映射，未读取卡片正文的来源声明。
3. 选择文件直接替换为包含正文片段的子图，右栏没有相关实体浏览列表。
4. 图谱每次数据刷新都删除所有元素并重新布局，拖动位置和视口无法保留。
5. 连线采用浅灰、1 像素、0.65 不透明度，实际初始缩放约 0.59，显示宽度不足 1 像素。小图自动适配未限制放大比例。

## 验收范围

验收以真实 API 和当前书稿为依据，检查正确识别和定位、三栏联动、关系可读性、布局保持、亮/暗/纸主题和窄窗口。自动化回归另使用原创材料覆盖同名实体、多书隔离、来源分级、旧版本升级、300 节点边界及原文失效。真实书稿只读，升级仅更新本书派生图谱；不为验收调用付费生成模型。

## 已落实的优化

| 视频中暴露的问题 | 本次实现 |
|---|---|
| 设定文件只出现文档或蓝色片段 | 补齐一至六级卡片标题、名称列表格和编号伏笔条目解析；过滤字段、占位栏目和空分组，节点保留对应卡片全文区段。势力格局/生态类标题按概念展示。 |
| 同名身份容易混为一人、计划容易误当已发生 | 节点按类型、文件和定义区段区分；仅使用原文声明的名称或别名，歧义名称不自动挂接。伏笔意向标为“计划 · 未埋设”，卡片来源与生成模型抽取分别保留。 |
| 点击文件丢掉上下文、右侧没有内容 | 默认保留全景，突出本文件的节点及有依据的边；右侧同步显示相关实体、摘要和出处。作者明确选择“只看此文件”才载入局部图，可返回本书全景。 |
| 连线淡、标签看不清、小图被过度放大 | 结构、提及、计划、明确关系使用不同连线样式与主题颜色；提高线宽及不透明度；缩放时调整标签字号，悬停显示完整名称。自动适配的放大上限为 1.15。 |
| 每次刷新都重新排列、窄小画布浪费空间 | 画布填满中栏，首次 CoSE 布局利用可用宽高；同书数据按 ID 增量更新，保留已拖动的位置和视口。筛选隐藏的节点恢复时读取本书位置缓存。 |
| 异步范围切换导致旧画面被当作新结果 | 同书新范围载入时保留旧画布但禁用操作，显示加载状态；列表及统计只使用已提交范围。切书取消旧请求、清空旧内容，再核验响应书籍标识。 |
| 节点详情与定位是整个分块，难以找到卡片 | 返回节点自身区段、全文起止行、hash 和证据 ID；优先加载定义出处，跳转前重新验明原文版本，编辑器精确选中卡片行。其余证据按每批 6 条继续加载。 |
| 解析器升级可能触发整书重新嵌入 | `grounded-graph-v2.2` 图谱版本独立于向量版本；兼容旧组合版本，从有效材料重建派生图谱，保留既有分块及向量，不为升级调用模型。 |

图谱仍遵守“出处先于关系”：名称提及仅作材料导航，不能当人物关系；无依据或已失效的节点和边不展示。图谱与节点 ID、任务、引用继续绑定服务端解析的本书 `knowledge_key`，并保持每书独立数据库。
