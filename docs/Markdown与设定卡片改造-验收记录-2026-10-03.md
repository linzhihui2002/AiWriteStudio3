# Markdown、AI 卡片、正文装饰与技能用量验收

本记录针对本次改造，保留工作区原有修改。小说原文仍是事实源；浏览器行为检查使用 8790 上的真实前端和隔离的请求样例，不写用户书稿、不调用真实模型。

## 实现

- Markdown 使用锁定的 react-markdown 10.1.0、remark-gfm 4.0.1，保留标准表格、对齐、转义竖线、列表、代码和安全换行。文档默认系统中文无衬线字体、16px、1.75 行高、最大 960px。明确来源字段、来源列及两列来源值转换中文小标签；普通英文与代码保持原样。
- 所有内置及自定义设定分类使用手动 AI 语义提取；读取、搜索、保存、分类及颜色操作不调用模型。后台任务校验原文依据、归属与版本，失败保留最后有效缓存，没有格式解析回退。旧缓存失效。对象 ID 和三主题颜色保存到本书元数据。
- CodeMirror 6 提供章节行号、软换行、撤销、精确选区及原文定位；名称、明确别名、闭合中文对话和阶段字数均为显示装饰。未闭合引号不蔓延，歧义名称不猜测。
- 按用户最后补充，字数阶段放在段落结束后的下一显示行，并左对齐；长段跨过多个档位时仅显示最新档位。底部总字数保持实时统计。编辑、预览、阅读共用原文位置，节点不进入保存或复制文本。
- 技能正文、单文件、总量和引用裁剪已删除。实际命中技能按优先级去重完整加载，引用按需读取。列表、详情、同步与对话步骤保留估算 token，未读取引用不计入注入量。
