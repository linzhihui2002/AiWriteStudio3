## 2. 各项目速览（按借鉴价值排序的要点）

### 2.1 EthanYoQ__AI-Novel-Writer ⭐（最直接的 DSH 集成范本）
- Electron + Vite + TS 桌面工作台；流程：前提→角色→世界观→章节蓝图→草稿→审稿→修稿→定稿
- `plugins/dsh-ai-novel-writer/` 是现成 DSH 插件：`presets/`（agent.cordis.yml + preset.yml）、`src/`（agent-v2.ts、context-window.ts、novel-store.ts、command-rpc.ts、client/workbench-v2.ts）、`tests/`（guardrails 快照测试）
- 核心机制：**Proposal 收件箱**（AI 起草先进本地编辑表单，用户审核应用才写入权威状态）；**来源标注的连续性材料**（作者填写/模型提炼/未知来源三级事实分级）；**逐项目标审稿**（关键事件逐项标已完成/未完成/待核实 + 正文证据，待核实不算通过）

### 2.2 voocel__ainovel-cli ⭐（架构思想最契合）
- Go CLI；**『事实层确定，语义层自主』**：确定性 Engine 按 Route 决策表调度（可穷举测试钉死），Architect/Writer/Editor 三个自主 LLM 循环，Arbiter 按需单次调用做语义裁定（裁定落盘可审计回放）
- 文件系统即事实层（Store）；Step 级 checkpoint（plan/draft/check/commit）崩溃精确恢复；卷弧双层滚动规划（初始只规划 2 弧）；自适应上下文策略（全量/滑窗/分层摘要按章数切换）
- Writer 每章固定工具序列：context→read→plan→draft→check→commit；Editor 七维质量评审强制引用原文举证

### 2.3 Mochocyang__QMAI ⭐（上下文工程最强）
- Tauri 2 + React 19 + Rust；Milkdown 编辑器、graphology/sigma 关系图谱；面向 200-300 万字连载
- **章节摄取**：保存后自动提取摘要/钩子/实体/事件/关系变化/角色认知/伏笔增删/时间线/图谱边，结构化落 JSON
- **上下文包**优先级组装：用户指定 > 本章细纲 > 上章结尾 > Canon 正史 > 人物状态 > 伏笔 > 摘要 > 正文片段 > 图谱 > 向量 > 关键词；带 token 预算裁剪 + 按真实模型输入上限重试
- 混合检索五路：最近章节窗口 + BM25 + 向量 + 图谱扩展 + Canon 强制注入

### 2.4 qin1473692580-ux__oh-story-claudecode ⭐（确定性闸口最完善）
- 13 个网文 skill + 多端适配（Claude Code/TRAE/CodeBuddy/ZCode/Codex），TRAE 注册 13 个 Agent
- 三层语言门（生成前锁定 zh → language_gate.js 落盘阻断 → Hook 复查拦截旧债）；跨章连续性守卫（位置/持有物进热上下文，改动必须逐字报旧值）；规划记号泄漏拦截 hook 网

## 3. 值得借鉴的 Top 设计模式（跨项目综合）

1. **『事实层确定，语义层自主』三层架构**（voocel）：确定性 Engine/Route 决策表做编排（零 LLM、可穷举测试），边界判断交给按需单次 Arbiter（裁定落盘可回放），开放式创作交给自主 Worker。
2. **Proposal 收件箱 + 人工应用才落权威状态**（EthanYoQ）：AI 产出永远是建议；配合 guardrails 快照测试钉死行为。
3. **上下文包 = 优先级清单 + token 预算 + 模型上限裁剪**（QMAI）：超限自动降级；检索五路混合。
4. **写后『章节摄取』自动沉淀记忆**（QMAI/Jieice/huahuakandaima）：每章 commit 时提取摘要/实体/关系变化/伏笔/时间线更新追踪四件套；读取侧分层（必读状态卡+前章末 500 字），不盲更全量。
5. **滚动规划与章节合同**（voocel/huahuakandaima）：只细化近端（前 2 弧/5-12 章）；每章写前签合同，写后逐项验收（『待核实不算通过』，EthanYoQ）。
6. **去AI味确定性双门禁**（qi531416/oh-story/huahuakandaima）：量化脚本硬门 + 模型软审；质检进度表逐章记录；客观文风指纹做对齐锚点。
7. **渐进式披露的协议化 Skill**（tianming/oh-story/novel-skill-cards）：协议文件 + 指令路由按需加载（token 降 50-70%）；知识库依赖门控；技能卡零依赖可插拔。
8. **质量债分级 + 非阻塞生产链**（ExplosiveCoderflome）：章级瑕疵记债放行、仅 replan 级停链；检查点恢复；Prompt Registry 注册制。
9. **拆书对标资产化**（analyze-hit-novel/oh-story/huahuakandaima）：拆解产物落 `拆文库/{书名}/` 成为可检索资产；结论强制附章节证据。
10. **跨章连续性硬守卫**（oh-story）：位置/持有物等易错状态进热上下文，任何改动必须逐字报旧值；『模型承诺不可信，用闸口兜底』。
