## 已实现的产品流程

资料/实体双目录；48px资料行；选文件默认局部图；节点一跳聚焦与返回；明确本书全景；资料/检索/待审三个详情页签。关系分定义、提及、明确关系和计划，内容片段按需展示，图例折叠，边标签选中/悬停出现。按书与范围保存位置和视口，增量刷新保留操作位置。

可用中栏不足600px时使用抽屉；窗口小于920px使用区域切换并默认图谱，全局导航临时收起，通过顶栏抽屉访问，不修改宽屏侧栏偏好。20个以内节点采用14px目标屏幕标签字号。图谱失败停止加载，保留画面标示实际旧范围，允许重试/返回；切书取消请求并清空旧书数据。节点定义依据定位到所选定义行，检索依据仍打开真实检索片段；均验证原文hash。

保存及外部变化检测按书合并5秒，仅分析变化材料，覆盖草稿、大纲、设定、状态。任务提供真实文件/分块进度与当前文件；取消拒收迟到结果，失败材料可重试。可见知识页空闲5秒检查一次，隐藏/离开停止，不增加全盘文件监控。

候选必须具备原文精确引句、跨度和版本；同名或别名歧义由作者选择。来源、审核状态、生命周期和章节范围分别保存。审核先生成同文件合并差异，确认写入后按文件变更凭据入库。草稿与计划进入计划分区，作者可明确确认为事实或已发生事件；未经确认不能进入历史上下文。

来源与目标变化、同名定义换序、提案正文/元数据篡改均拦截。合法同批计划追加不会误使兄弟关系提案失效。已确认字段的后续修订替换旧记录。staging事务丢失、跨库补账失败和重复应用通过持久Proposal与journal恢复，不重写作者之后的修改；普通重建保留审核记录。

同一文件兼作来源与写入目标时，已应用候选可从其核验过的journal before-image查看审核时原文。书籍、候选、提案、提交凭据、原版本hash及精确引句均须匹配；打开当前资料不携带旧行号或旧hash。已应用候选的现有值和冲突标为“审核前内容”和“审核时的冲突”，避免误报为当前冲突。归档能力不放宽未应用候选的审核与提交版本门禁。

图谱版本为`grounded-graph-v3.3-reviewed-lifecycle`，向量版本保持不变。已审核关系按知识ID保留独立身份，同关系的计划、历史或不同章节范围不会合并丢失状态。历史检索、设定、状态和伏笔直读共用生命周期过滤；原始大纲只在规划检索与图谱/证据读取中出现。

## 本轮验收发现并修复

- 同文件多个候选导致同一Proposal重复显示；按Proposal ID去重。
- 计划新实体的分区标题曾落在生命周期标记外，可能泄漏名称到历史；标题放入受保护记录并验证历史检索与上下文。
- 大纲历史过滤误伤graph/evidence；保留规划和图谱/原文定位，继续排除历史场景。
- 同批人物计划写入使兄弟关系提案误失效；改为精确实体定义核验，同时继续拒绝身份改变和同名换序。
- 长元数据遮罩空格触发字段正则回溯卡顿；按行跳过空白并保留原文位置。
- 同关系不同知识生命周期或章节范围合并；按知识ID独立投影，检索去重也保留不同记录。
- 选实体打开依据曾定位整个检索片段；版本及片段校验后定位所选定义，过期依据拒绝。
- 写回同来源文件后旧全文hash失效，已应用候选无法读审核依据；新增严格绑定提交凭据的journal归档读取，未应用候选仍拒绝旧版本。
- 窄窗口全局导航占用图谱空间；仅知识路由临时收起，覆盖抽屉保留焦点控制、Escape关闭和个人偏好。
- 已应用候选仍出现审核期间的失效提示；将旧值、冲突标为审核历史，失效提示仅用于失效候选。
- 原定义删除后旧测试曾要求删除AI审计记录；保留候选及有效原始证据并标失效，移除图谱投影且禁止审核应用。删书时的延迟任务也不再产生未处理线程错误。

## 重复验收

从工作树根运行隔离Python环境的`python -m workbench.backend.tests.knowledge_acceptance_server`，再用Node执行前端browser acceptance脚本。`WORKBENCH_PLAYWRIGHT`可指定本机Playwright包，浏览器使用安装的Chrome；`WORKBENCH_ACCEPTANCE_RUN=knowledge-acceptance-<小写标识>`为每次写回验收创建新临时书目录，避免复用已应用的状态。后端完整命令为`python -m pytest workbench/backend/tests -q`，前端为`npm run test`与`npm run build`。

临时运行库、浏览器截图和测试日志均位于当前工作树`.workbench/`，不导入主工作区、不属于小说材料。
